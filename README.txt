ANUSHA'S PORTFOLIO - HOW TO DEPLOY

1. Compile your LaTeX resume to PDF (Overleaf works well), name it resume.pdf
   and put it in this folder next to index.html. The "Download Resume" button uses it.

2. DEPLOY ON NETLIFY (fastest):
   - Go to app.netlify.com/drop
   - Drag this whole folder onto the page
   - Your site is live. Rename the link in Site settings.

3. DEPLOY ON VERCEL (best for updates):
   - Upload this folder to a new GitHub repo named "portfolio"
   - Go to vercel.com > Add New > Project > pick the repo > Deploy

4. Test on your phone, then add the link to your resume, LinkedIn and GitHub.

TO EDIT: open index.html in VS Code. Accent color = --accent near the top.
